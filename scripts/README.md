# Scripts

Developer convenience scripts. Nothing here is required — every step can be
run by hand from the root README.

| Script | Purpose |
| --- | --- |
| `setup.ps1` | One-time local setup on Windows (venv, npm install, `.env` files) |
| `setup.sh` | The same, for macOS and Linux |

Planned additions: database seeding, DataHub sample-metadata ingestion, and a
demo reset script.
